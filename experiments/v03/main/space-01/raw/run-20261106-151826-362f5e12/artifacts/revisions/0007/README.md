# Space Fractions

A sixth-grade fraction-learning system: play a game, answer fraction questions with
exact rational arithmetic, pause/resume, and view your score. Admins maintain the
question bank. The system is built as a set of Node.js/Express microservices behind a
single browser gateway, with PostgreSQL as the durable source of truth for all game
state.

This repository is generated from the original architecture documents
(`Architecture_Documentation.md` and `Architecture_View.md`) and the operator-supplied
acceptance contract (`space-fractions.md`). See `architecture-decisions.md` for the
full decision record, deviations, and assumptions.

## Architecture overview

| Service             | Responsibility |
| ------------------- | -------------- |
| `gateway`           | Browser UI, `GET /health`, OIDC login (PKCE S256), route multiplexing, `GET /play`. Container port **3000**. |
| `game-service`      | Game lifecycle, question selection (stable order), answer scoring, pause/resume, score view, owner authorization. |
| `question-service`  | Authenticated question retrieval and Elasticsearch-backed search (real client). |
| `user-service`      | User profile resolution, `sub`-to-numeric-ID mapping, account audience. |
| `admin-service`     | Admin-only question CRUD and `GET /api/admin/questions`. |
| `postgres`          | Owns all game state, one owned transaction client, rollback on error, idempotent migrations/seeds. |
| `redis`             | Cache-only game-state (PostgreSQL remains authoritative). |
| `rabbitmq`          | Score events. |
| `elasticsearch`     | Question search. |
| `keycloak`          | OIDC identity provider (24.0.5). Container port **8080**. |
| `prometheus`        | Metrics registry scrape target. |

## Runtime requirements

- **Node.js >= 22** (the supplement takes precedence over the original "Node 18-20").
- **Docker + Compose** for the full local runtime (`compose.yaml`).
- PostgreSQL, Redis, RabbitMQ, Elasticsearch, Keycloak, and Prometheus are provided by
  Compose; you do not need them installed locally for the default unit tests.

## Local / Compose run

Copy the environment template and adjust (placeholders only — never commit real secrets):

```bash
cp .env.example .env
```

Start the full stack (Compose service IDs are exactly those listed above):

```bash
docker compose up --build
```

Public URLs derive from `PUBLIC_ORIGIN` / `OIDC_ISSUER` / `OIDC_PUBLIC_ORIGIN` in
`.env` — never from a fixed host port, because test runtimes remap ports. With the
default `.env.example`:

- Browser UI: `http://localhost:3000`
- Health: `http://localhost:3000/health`
- Keycloak (public frontend): `http://localhost:8080`
- Prometheus metrics: `http://localhost:9090` (per-service `METRICS_PORT`)

## Demo accounts (local-only)

The Keycloak realm import defines these local-only demo users; **do not use these as
production guidance**:

| Username | Password | Role |
| -------- | -------- | ---- |
| `student` | `student` | learner (plays games, views own score) |
| `admin`   | `admin`   | learner + `admin` realm role (question CRUD) |
| `other`   | `other`   | learner (used to assert owner authorization, i.e. 403/404 on others' games) |

> All profile names are non-empty. The public browser client `space-fractions-client`
> uses the authorization-code flow with PKCE S256. Direct access grants are enabled
> **only** for the local demo fixture (password grant used by the independent HTTP
> fixtures). The host acceptance harness configures its own temporary-port origin via
> Keycloak administration.

## Tests

- **Unit tests** (default `npm test`): run with `node:test` against in-memory
  adapters — no live PostgreSQL, Redis, or identity provider required. They cover
  scoring (exact rational arithmetic), pause/resume, authorization (403/404),
  invalid input, and error behavior.
- **Integration tests** (`npm run test:integration`): exercise real PostgreSQL
  transaction semantics for score dedup. These are separate and require a running
  database (see `.env.example` and `compose.yaml`).

```bash
npm test                 # unit tests, no infrastructure required
npm run test:integration # PostgreSQL-backed, separate and documented
```

## Environment variables

See `.env.example` for the full annotated list. The most important:

- `PUBLIC_ORIGIN` — public browser origin (redirects derive from it).
- `OIDC_ISSUER` / `OIDC_PUBLIC_ORIGIN` — identity-provider public URLs.
- `OIDC_JWKS_URI` — internal Keycloak certs endpoint
  (`http://keycloak:8080/realms/space-fractions/protocol/openid-connect/certs`).
- `OIDC_CLIENT_ID`, `OIDC_AUDIENCE` — client and audience.
- `PGHOST` / `PGPORT` / `PGDATABASE` / `PGUSER` / `PGPASSWORD`.
- `REDIS_URL`, `AMQP_URL`, `ELASTICSEARCH_URL`, `METRICS_PORT`, `HTTP_TIMEOUT_MS`.

## Architecture deviations and unverified infrastructure

- **Deviations** are recorded in `architecture-decisions.md` (AD-1 … AD-9):
  a fourth `admin-service` entrypoint added per the supplement (original lists three
  components); Node 22+ adopted over the original Node 18-20; and an error-budget
  arithmetic discrepancy noted from the source (99.99% SLO vs "1% error budget").
- **Reference-only configs** under `k8s/`, `Jenkinsfile`, `terraform/`, and `ops/`
  (Vault, Istio) are provided as clearly labeled reference material and are **not**
  claimed production-validated. No performance, availability, deployment, or security
  validation results are fabricated.

## API contract

REST surface is documented in `openapi.yaml`; the internal contract is in
`internal.proto`. Notable endpoints:

- `GET /health`
- `GET /` (browser UI), `GET /play`
- `POST /api/games`, `GET /api/games/:id`
- pause/resume and answer submission on a game
- `GET /api/games/:id/score`
- `GET /api/admin/questions` → `{ questions: [{ id, prompt, options, correctAnswer }] }`
