# v0.2 实验协议（正式运行前冻结）

v0.1 及 v0.2-development 是开发/排错过程，不合并为固定基准实验。v0.2 的正式 cohort 使用独立 manifest，固定控制器、通用提示词、案例补充、原始输入和项目外检查器的 SHA256；运行中修改这些文件会使该 cohort 停止，不能静默替换结果。

## 固定设置

- 百炼 deepseek-v4-pro-0813，非思考模式，最大输出16384；300个模型轮次上限，300秒单次请求期限。计价按本次已核对的北京快照上界9/27元每百万tokens记录；不设金额上限，不清空历史账本。
- 原始 Space Fractions 从空目录运行3次，最多3轮宿主反馈修复。图书借阅案例分别使用0轮和3轮宿主修复，各3次，共9个正式任务。
- 两种借阅配置共享相同工具和生成方式；生成阶段只允许静态检查，其余测试在生成结束后统一执行。0轮组仍接受最终验收，但失败不再反馈给模型；不将其描述成“模型从未接触任何检查”。
- 不使用seed，不人工修改正式生成项目。所有失败和中断保留，不通过额外重复挑选好看的结果。
- 锁文件由宿主固定 `npm install --package-lock-only --ignore-scripts` 派生并保存来源及快照，再运行 `npm ci`；不是人工修改业务源码。借阅0/3轮组按重复编号交替执行，减少先后顺序的单侧影响，但不属于随机试验。

## 独立运行验收

宿主选择 Docker CLI 或现有 WSL Ubuntu Docker，检查 Compose 文件引用后渲染配置。宿主只在项目外调整部署名称、回环端口和身份提供方公共来源，记录隔离配置，不重写生成源码。独立检查器不在模型可写目录。

游戏检查：真实OIDC登录、错误签名、管理员权限、所有权、暂停恢复、等价/非法分数、8个并发重复答案、第二题计分、结束后重复提交、服务重启持久化及夹具清理。借阅检查：输入错误、并发抢唯一库存、并发重复归还、重复借阅和重启后书籍/借阅持久化。浏览器入口实际返回200；界面可用性另做真实浏览器检查。

每次运行保存构建/启动/重启/日志/清理的结果。只清理本次唯一项目的容器、网络和测试卷，不影响此前演示实例。Docker执行不是操作系统安全沙箱。

## 报告口径

分别报告构建、项目自带测试、项目外HTTP验收、人工介入、模型轮次、重复读取、工具参数错误、耗时和费用。没有运行的检查标记unverified；未提供可选集成脚本标记not_applicable，不计为通过。成功仍需人工审查设计语义。

3次是小样本可行性观察，不进行显著性、普遍成功率或多Agent优势声明。若未获得无需人工修改的完整成功案例，如实报告失败模式，不放宽独立检查。

运行入口：`python scripts/run_benchmark.py --cohort <独立名称> --confirm-pricing`。源码冻结后可恢复尚未开始的任务；发现残留running试验时必须先明确核实和标注中断，不能自动重跑覆盖。

可在对应 cohort 目录创建 `STOP` 文件请求合作取消：等待当前网络请求结束/超时后保存报告并清理运行环境，不发送全局控制台中断。删除这个文件仅用于明确计划恢复时；已记录的试验不自动重跑。

只读汇总入口：`python scripts/summarize_benchmark.py experiments/v02/<cohort>`。按每次运行的有效响应usage估算费用；全局账本的差额可能包含并行开发调用，不用作分组成本比较。网络不确定预留另外披露。

## 开发 pilot 与冻结版本

`20261106-v02-e1` 首次运行在尝试让模型编写 npm 锁文件时出现输出截断，操作者中止控制器。保留原始目录、事件和不确定请求费用；结果标记 `externally_interrupted_controller_defect`。更改锁文件机制后，重新建立 `20261106-v02-e2` 冻结 cohort。e1 不视作完成的九次对照，不将其缺陷抹除。
